# King Hub

Loader che rileva il gioco e carica lo script giusto dal repo. by MIRKO KING YT

## Uso

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Mirko1926/mirko-hub/main/loader.lua"))()
```
