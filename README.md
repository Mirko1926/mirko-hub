# Mirko Hub

Loader che rileva il gioco e carica lo script giusto dal repo.

## Uso

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Mirko1926/mirko-hub/main/loader.lua"))()
```

## Giochi supportati

| Gioco    | PlaceId       | Script               |
|----------|---------------|----------------------|
| Arsenal  | 286090429     | `scripts/arsenal.lua`|
| One Tap  | 90568084448279| `scripts/onetap.lua` |
| Rivals   | 17625359962*  | `scripts/rivals.lua` |

\* PlaceId Rivals da confermare.
